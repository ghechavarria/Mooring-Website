Website Update — Reposition Mooric as the Broker-Side Process Platform
We're sharpening the site's core message. Right now the site presents Mooric as a set of features (AI 1003, tracking, pipeline). The update: present it as one connected system for the entire broker-side process, with the features as stages inside it.
1. New hero headline (replace current):
One workspace for the entire broker-side process.From the first borrower conversation to closed loan — intake, AI-completed 1003, conditions, TRID, title, appraisal, and pipeline, all in one place. No more Excel trackers, no more four systems.
2. LOS compatibility line (new — place directly below the hero, or as the first FAQ):
Works alongside your existing LOS. Run your entire process in Mooric, then hand off a clean MISMO 3.4 file when it's time to submit. No migration, no rip-and-replace.
This addresses the #1 buying objection (fear of switching systems). Use "alongside" — not "integrates with" — we do not have live LOS integrations yet.
3. Add a process-flow section (new, below hero):
A horizontal visual of the loan journey with four stages — Prospect → Application & Setup → Processing → Closed — each with one line:
Prospect: Every lead and conversation logged, ready to become a file.
Application & Setup: Upload borrower docs — AI completes the 1003, you review side by side.
Processing: Conditions, TRID deadlines, title, HOI, appraisal — tracked on one screen, updated as things come in.
Closed: Clean handoff, full file history, audit-ready records.
4. Reframe existing feature sections as stages of this flow rather than standalone features. Keep the content, change the framing: each section header gets a stage label (e.g., "PROCESSING — Condition & deadline tracking").
5. Wording rules:
Use: "one workspace," "one system," "the entire broker-side process," "end to end," "works alongside your existing LOS"
Avoid: "all-in-one" (over-promises against current scope), "CRM" (invites wrong comparisons), "LOS" as a self-description, "replaces your LOS," "integrates with your LOS" (implies live sync we don't have)
Audience wording: "independent LOs and broker shops" — no "small"
