# Contact CTA (`ContactCTA.tsx`)

Blue (`bg-erp`) band at `#contact`. Order: mono eyebrow → display headline → supporting sentence → early-access button.

## Eyebrow

`Let's talk` — `font-mono`, uppercase. Size `text-sm` / `sm:text-base` with tracking `0.22em` / `0.24em` and `text-white/90` so it stays readable on the solid blue field.

## CTA

Outlined white button opens the contact modal (`walkthrough`). Hidden when `SHOW_CONTACT_ACTIONS` is false.
